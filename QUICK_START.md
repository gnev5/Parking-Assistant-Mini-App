# ParkShare - Quick Start Guide

## Getting Started

### For Users (Testing the App)

1. **Open the App**
   - If deployed as a Telegram Mini App, open via your Telegram bot
   - For web testing, simply open the deployed URL

2. **First-Time Setup**
   - Enter your name
   - Add your Telegram username (e.g., @yourusername)
   - Optionally add phone number
   - Toggle "I own a parking space" if you're an owner

3. **As a Parking Space Owner**

   **Step 1: Add Your Parking Spaces**
   - Click "My Parking Spaces"
   - Click "Add" button
   - Fill in:
     - Space number (e.g., "A-123")
     - Location (e.g., "Building 1, Level 2, near elevator")
     - Your contact details
   - Save

   **Step 2: Create Listings**
   - Go back to home
   - Click "Create Listing"
   - Choose listing type:
     - **For Sale**: Set a price, describe the space
     - **Long-term Rental**: Set monthly rent, availability date
     - **Guest Parking**: Set hourly/daily rate and specific time range
   - Select which parking space (or leave blank)
   - Add description
   - Submit

4. **As a Member (Looking for Parking)**

   **Browse What's Available**
   - Click "Browse Listings"
   - Use tabs to filter: All, Sale, Rental, Guest
   - View details and contact owners directly

   **Post What You Need**
   - Click "Post Request"
   - Choose request type:
     - **Looking to Buy**: Describe what you want
     - **Looking for Rental**: Set budget, needed dates
     - **Need Guest Parking**: Specify exact dates/times needed
   - Add your budget and description
   - Submit

5. **Contacting Others**
   - Click "Telegram" button to open chat
   - Click "Call" button to dial phone
   - Direct peer-to-peer communication

## Common Use Cases

### Scenario 1: Going on Vacation
You have a rented parking space but will be traveling for 2 weeks:
1. Click "Create Listing"
2. Choose "Short-term / Guest Parking"
3. Set dates: Jan 25 - Feb 7
4. Set rate: "$10/day"
5. Post! Help a neighbor while earning some money.

### Scenario 2: New Resident Looking for Parking
Just moved in and need monthly parking:
1. Click "Post Request"
2. Choose "Looking for Long-term Rental"
3. Budget: "Up to $150/month"
4. Start date: "February 1"
5. Post and wait for owners to contact you!

### Scenario 3: Visitor Coming This Weekend
Need parking for a guest on Saturday:
1. Click "Post Request"
2. Choose "Need Short-term Parking"
3. Set dates: "Jan 27, 9 AM - Jan 27, 8 PM"
4. Post request
5. Browse listings for immediate options

### Scenario 4: Selling Your Parking Space
Moving out and want to sell your deeded space:
1. First add your space in "My Parking Spaces"
2. Click "Create Listing"
3. Choose "For Sale"
4. Set price: "$25,000"
5. Link to your parking space
6. Add photos in description
7. Post!

## Troubleshooting

**"I can't create a listing"**
- Make sure you've enabled "I own a parking space" in your profile
- For linking to a space, add spaces in "My Parking Spaces" first

**"Telegram button doesn't work"**
- Ensure the username starts with @ (e.g., @username)
- The other person must have their Telegram username set

**"I don't see any listings"**
- Check if you're using filters - try "All" tab
- Be the first to post! Create a listing or request

**"How do I edit my listing?"**
- Currently, create a new listing with updated info
- Contact admin to remove old listings

**"Is my data secure?"**
- This app is designed for trusted community use
- Only share contact info you're comfortable with
- No payment data is stored
- Use for coordination, handle payments separately

## Best Practices

1. **Complete Your Profile**: More info = more trust
2. **Use Clear Titles**: "Covered space A-123, near entrance" > "Parking"
3. **Price Fairly**: Check other listings for market rates
4. **Be Responsive**: Reply to inquiries within 24 hours
5. **Update Quickly**: Mark as sold/rented promptly
6. **Add Details**: Location, covered/uncovered, size, restrictions
7. **Be Honest**: Accurate descriptions build community trust
