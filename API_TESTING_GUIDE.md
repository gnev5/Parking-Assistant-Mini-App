## 📋 Описание проблемы

Кнопка "Сохранить профиль" в приложении не работает. Предполагается, что проблема в некорректном подключении к бекенду Supabase.

## 🔍 Анализ архитектуры

### Текущая структура
```
Frontend (React) 
    ↓ HTTP POST
API Gateway (Supabase Edge Function)
    ↓ /functions/v1/make-server-48e86749/users
Hono Server (Deno)
    ↓ kv.set()
Supabase Database → kv_store_48e86749 (таблица)
```

### Найденные эндпоинты

#### 1. **Health Check**
- **URL:** `GET /make-server-48e86749/health`
- **Назначение:** Проверка доступности сервера
- **Ожидаемый ответ:** `{ "status": "ok" }`

#### 2. **Создание/обновление пользователя**
- **URL:** `POST /make-server-48e86749/users`
- **Параметры:**
  ```json
  {
    "userId": "string (обязательно)",
    "name": "string (обязательно)",
    "telegramUsername": "string (опционально)",
    "phoneNumber": "string (опционально)",
    "isOwner": "boolean (опционально)",
    "language": "string (опциональн��, по умолчанию 'en')"
  }
  ```
- **Ожидаемый ответ:**
  ```json
  {
    "success": true,
    "user": {
      "userId": "...",
      "name": "...",
      "telegramUsername": "...",
      "phoneNumber": "...",
      "isOwner": false,
      "language": "ru",
      "createdAt": "2026-02-08T..."
  ```

#### 3. **Получение профиля пользователя**
- **URL:** `GET /make-server-48e86749/users/:id`
- **Ожидаемый ответ:** `{ "user": {...} }` или `{ "error": "User not found" }` (404)

## 🛠️ Инструкция по тестированию

### Шаг 1: Получение учетных данных Supabase

1. Откройте ваш проект в Supabase Dashboard
2. Перейдите в раздел **Settings** → **API**
3. Скопируйте следующие данные:
   - **Project URL** (н��пример: `https://cerplyttnwbcgtcvsbbd.supabase.co`)
   - **Anon/Public Key** (ключ для публичного доступа)

### Шаг 2: Запуск тестового инструмента

1. Откройте файл `test-api.html` в браузере
2. Вставьте скопиров��нные **Supabase URL** и **Anon Key** в соответствующие поля
3. Данные автоматически сохраняются в localStorage браузера

### Шаг 3: Выполнение тестов

#### Тест 1: Health Check
1. Нажмите кнопку **"🔍 Проверить Health Check"**
2. ✅ Успех: вы должны увидеть `{ "status": "ok" }`
3. ❌ Ошибка: проверьте URL и ключ API

#### Тест 2: Создание пользователя
1. Заполните поля:
   - User ID: `test-user-123`
   - Имя: `Тестовый Пользователь`
   - Другие поля (опционально)
2. Нажмите **"➕ Создать пользователя"**
3. ✅ Успех: получите `{ "success": true, "user": {...} }`
4. ❌ Ошибка: изучите сообщение об ошибке

#### Тест 3: Получение пользователя
1. Используйте тот же User ID из предыдущего шага
2. Нажмите **"🔍 Получить пользователя"**
3. ✅ Успех: получите данные созданного пользователя
4. ❌ Ошибка 404: пользователь не найден (возможно, не был создан)

#### Тест 4: Полная диагностика
1. Нажмите **"🚀 Запустить полную диагностику"**
2. Система автоматически выполнит все тесты последовательно
3. В конце вы получите итоговый отчет

### Шаг 4: Проверка в консоли браузера

Откройте DevTools (F12) и проверьте:
- **Network Tab:** Посмотрите статус-коды ответов (200, 404, 500 и т.д.)
- **Console Tab:** Проверьте наличие ошибок CORS или других проблем

## 🐛 Возможные проблемы и решения

### Проблема 1: CORS ошибки
**Симптом:** `Access-Control-Allow-Origin` ошибка в консоли

**Решение:** Проверьте настройки CORS в `supabase/functions/server/index.tsx`:
```typescript
app.use(
  "/*",
  cors({
    origin: "*",
    allowHeaders: ["Content-Type", "Authorization", "apikey"],
    allowMethods: ["GET", "POST", "PUT", "DELETE", "OPTIONS"],
  }),
);
```

### Проблема 2: 404 Not Found
**Симптом:** Эндпоинт не найден

**Возможные причины:**
1. ❌ Неправильный URL функции
2. ❌ Функция не развернута в Supabase
3. ❌ Неправильное имя функции (должно быть `make-server-48e86749`)

**Решение:** Проверьте деплой функции в Supabase:
```bash
# Если используете Supabase CLI
supabase functions deploy make-server-48e86749
```

### Проблема 3: 500 Internal Server Error
**Симптом:** Сервер возвращает ошибку 500

**Возможные причины:**
1. ❌ Ошибка в коде сервера
2. ❌ Проблемы с доступом к базе данных
3. ❌ Отсутствует таблица `kv_store_48e86749`

**Решение:** 
1. Проверьте логи функции в Supabase Dashboard
2. Убедитесь, что таблица создана:
   ```sql
   CREATE TABLE kv_store_48e86749 (
     key TEXT NOT NULL PRIMARY KEY,
     value JSONB NOT NULL
   );
   ```

### Проблема 4: Переменные окружения не установлены
**Симптом:** Ошибка при подключении к базе данных

**Решение:** Проверьте, что в Supabase Function Settings установлены:
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
